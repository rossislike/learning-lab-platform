You just did the three things every Git workflow is built on:

1. `git init` — create a repository.
2. `git add` — choose what the next snapshot contains.
3. `git commit` — record the snapshot with a message.

Everything else in Git (branches, merges, remotes) is built on top of commits
like the one you just made. Try editing `day1.md` and making a second commit
before the session ends.
