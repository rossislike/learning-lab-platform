# Add Empty State Message

## Challenge Description

This is a quick React fundamentals scenario. The task list can render items, but it currently shows nothing when the list is empty.

## Requirement

Edit `src/App.jsx` so an empty task list shows exactly:

```text
No tasks yet. Add your first task to get started.
```

Run checks when the preview shows the empty state message.
